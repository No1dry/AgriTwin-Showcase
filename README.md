# AgriTwin Showcase

[在线情报总览](https://no1dry.github.io/AgriTwin-Showcase/)

农业情报的独立展示站。左侧固定为上下两区：外部情报与内部信息，右侧为连续卫星地图，文章详情悬浮于地图内部。页面无导航栏，不展示模型品牌、调用量、源码和哈希等工程字段。内部信息依照用户要求保留传感器指标，缺少数据时显示 N/A。

## 使用

- 搜索情报；按分类展开或收起列表。展开后显示全部文章，只有整个外部情报内容区滚动，分类卡片不再单独滚动。
- 左栏本身不滚动；外部、内部两区的标题与位置固定，各自内容可独立上下滚动。常用桌面默认完整显示内部指标和天气曲线，小屏保留两个子区并在各区内浏览。
- 内部信息展示空气温度、空气湿度、土壤含水率、土壤 pH 的日均值及最高/最低值位置。真实传感器数据尚未提供，数值与近7日趋势均为 N/A，不绘制示例曲线。
- 天气变化使用真实 Open-Meteo 小时数据，支持近7日日均气温与累计降水切换；与农场传感器分开，明确标注区域模型数据。
- 点击文章打开地图内详情，可阅读摘要、原文依据、相关资料与原文出处。关闭详情不改变地图尺寸。
- “订阅专题”选择首页关注的类别；专题和已选简报保存在当前浏览器本地。这是内容偏好，不提供邮件推送。
- “加入简报”保存单篇；“生成简报”打开已选内容，未选时汇集当前筛选结果；“导出”下载 Markdown。
- 地图支持拖动、缩放、返回梁子湖、全区概览、比例尺与天气图层开关。

## 数据与运行

浏览器优先读取 AgriTwin-Intelligence 的 public/external/latest.json，网络失败时使用站内真实快照；过期资料显示更新时间提示。页面展示来自真实调用的摘要，本次界面重构不新增模型调用。

内部农场数据仍未进入公开数据包（`internal: null`），N/A 仅为用户要求的界面占位，不代表任何实测记录；不绘制虚构地块或塘口边界。Esri World Imagery 为真实历史卫星/航空影像，保留原始署名。

天气由浏览器请求 Open-Meteo 免费公开接口，坐标为梁子湖区域中心 30.1417, 114.625，无需密钥或模型调用。读取8天历史和当日小时序列，默认按北京时间最近一个已结束的12:00至次日12:00周期汇总。中午之前显示前一个完整周期，避免将尚未发生的小时计入日均。近7日横轴为各统计周期结束日期。

温度、湿度、风速使用 `[start,end)` 的24个时点取平均；降水按官方定义为此前1小时累计，使用 `(start,end]` 的24个小时值求和。单指标缺少任何小时则保持 N/A，曲线断开；真实零降水仍显示0。`past_days` 是历史预报模型数据，不是农场传感器或气象站实测。来源、单位和更新时间都在页面内可查；失败显示空状态并提供重试，不生成假天气。接口调用适用于当前独立非商业测试；商用部署前核对 [Open-Meteo 使用条款](https://open-meteo.com/en/terms)。变量说明见 [官方文档](https://open-meteo.com/en/docs)。

来源可用性、失败原因、模型调用量与证据哈希继续保留于引擎输出和 Actions；用户阅读界面只显示必要的来源与资料信息。无原文照片的卡片使用分类图形，不能理解为现场照片。当前仅 NMC 2026-10-12 周报使用对应官方正文配图。

## 开发与部署

Node.js 24，无前端依赖。`npm test` 验证数据与发布边界以及天气的时区、累计口径和缺测处理，`npm run build` 生成 dist，`npm run serve` 启动本地预览。构建只允许5个公开文件，所有脚本和样式带内容版本号；校验天气脚本在应用脚本前加载，避免分批上传期间发布不完整版本。

main 提交后由 Pages workflow 自动测试、构建与发布；无模型密钥、无付费定时任务。引擎采集在独立仓库 Actions 手动触发，不暴露为用户页面跳转。

产品要求见 [AGENTS.md](AGENTS.md)。设计与验收文档统一保存于 [对话归档](https://github.com/No1dry/AgriTwin-Intelligence/tree/main/docs/conversation-archive)。
